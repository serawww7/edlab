Самостійна робота

Скопіюйте промпт і згенеруйте свій інструмент у будь-якому ШІ.

Створи один самодостатній HTML-файл (увесь CSS і JavaScript всередині файлу, без CDN і зовнішніх бібліотек) — мобільний генератор чеків 58 мм для агросервісу українською мовою.

Потрібні поля:
- тип чека (select): «ПММ — видача пального» або «Інструмент — видача/повернення»;
- агрегат (текст), оператор (текст);
- для ПММ: кількість пального, л (число);
- для інструменту: назва інструменту, дія (ВИДАЧА / ПОВЕРНЕННЯ).
Поля мають ховатися/показуватися залежно від типу чека.

Функції:
- кнопка «Зібрати чек» — оновлює попередній перегляд стрічки 58 мм (ширина ≈58mm, моноширинний вигляд);
- на чеку: заголовок «АГРОСЕРВІС · КВИТАНЦІЯ», дата/час, тип, агрегат, оператор, відповідні поля, Ref (наприклад LOCAL-XXXX), місце для підпису;
- кнопка «Зберегти як TXT» — скачує текстову копію чека.

Обовʼязкове доповнення: зберігати останні введені значення в localStorage і відновлювати їх при відкритті сторінки.

Інтерфейс зручний для телефону. Файл має відкриватися офлайн у мобільному браузері після збереження як .html.
Наприкінці покажи контрольний приклад: тип ПММ, агрегат МТЗ-82, оператор Іван, 12 л — і виведи готовий текст чека.
